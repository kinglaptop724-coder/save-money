# ระบบออมเงินนักเรียน — GitHub Pages + Google Sheet

หน้าเว็บ (`index.html`) อยู่บน GitHub Pages ส่วนข้อมูลยังอยู่ใน Google Sheet เดิม
โดย `Code.gs` ทำหน้าที่เป็น API (Apps Script Web App) ที่หน้าเว็บเรียกผ่าน `fetch`

## 1) ฝั่ง Google Sheet / Apps Script
1. เปิด Google Sheet เดิม → ส่วนขยาย → Apps Script
2. แทนที่เนื้อหา `Code.gs` ด้วยไฟล์ใหม่ในโฟลเดอร์นี้ (ลบไฟล์ `Index` เดิมใน Apps Script ได้ ไม่ใช้แล้ว)
3. Deploy → การติดตั้งใหม่ → ประเภท **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
4. คัดลอก URL ที่ลงท้ายด้วย `/exec`
5. (แนะนำ) Project Settings → Script properties → เพิ่ม `ACCESS_KEY` = รหัสที่ต้องการ
   หน้าเว็บจะถามรหัสนี้ครั้งแรกแล้วจำไว้ในเบราว์เซอร์ ไม่ตั้งก็ได้ (จะไม่มีการเช็ค)

> ทุกครั้งที่แก้ `Code.gs` ต้อง Deploy → จัดการการติดตั้ง → แก้ไข → เวอร์ชันใหม่ ไม่เช่นนั้น URL เดิมยังใช้โค้ดเก่า

## 2) ฝั่ง GitHub
1. แก้ `config.js` วาง URL `/exec` ลงใน `API_URL`
2. สร้าง repo แล้วอัปโหลดทุกไฟล์ในโฟลเดอร์นี้ (ยกเว้น `Code.gs`, `README.md`) รวมโฟลเดอร์ `icons/`
3. Settings → Pages → Branch: `main` / root → Save
4. เปิด `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## สิ่งที่เปลี่ยนจากเดิม
- `google.script.run` ถูกจำลองด้วย `gas-bridge.js` โค้ดเดิมใน `index.html` แทบไม่ถูกแก้
- `doGet` ตอบ JSON สถานะ, `doPost` เป็นตัวรับคำสั่ง และอนุญาตเฉพาะฟังก์ชันที่หน้าเว็บใช้จริง 43 ตัว
- สิทธิ์ "แอดมิน" เดิมเช็คจากอีเมล (`krutansoncom@gmail.com`) ซึ่งใช้ไม่ได้นอก Google แล้ว
  เปลี่ยนเป็น: ใครกรอกรหัสแอดมินผ่านแล้วถือเป็นแอดมิน
- ชื่อผู้ใช้มุมบนขวา (จากอีเมล) จะไม่แสดง

## ติดตั้งเป็นแอปบนมือถือ (PWA)
- เปิดเว็บผ่าน HTTPS (GitHub Pages เป็น HTTPS อยู่แล้ว)
- **Android (Chrome):** จะมีแถบ "ติดตั้งแอป" ขึ้นที่ด้านล่าง หรือเมนู ⋮ > ติดตั้งแอป
- **iPhone (Safari):** แตะปุ่มแชร์ > เพิ่มไปยังหน้าจอโฮม (ต้องใช้ Safari เท่านั้น)
- แก้ไฟล์เว็บแล้วอยากให้เครื่องผู้ใช้โหลดของใหม่ ให้เปลี่ยน `VERSION` ใน `sw.js`
- การบันทึก/ดึงข้อมูลยังต้องต่ออินเทอร์เน็ต (ไม่แคชคำสั่งที่ไปหา Google Sheet)
